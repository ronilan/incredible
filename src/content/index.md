# What is Incredible?

> *Nothing is incredible; its very existence makes it credible*.

## No Seriously, what is Incredible?

> **Incredible is a Rust Text User Interface (TUI) Framework for the 2nd Quarter of the 21st Century.**

Incredible is **New**, **Experimental**, **Modular**, **Declarative**, **Event Driven** and **Reactive**. It builds cross-platform apps that can be compiled for the **terminal** (macOs, Windows, Linux), a standalone **native window** (macOS & Windows 11), or the **browser** (via WASM) from one unified code base.

The framework is built from the ground up following basic UI principles. It implements an event loop, a typed element tree structure and a declarative theming engine. It allows the composition of new elements from encapsulated and/or fully reusable sub elements. It provides out of the box support for most modern terminal capabilities.
